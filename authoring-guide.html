Type 1 Standard

Multiple Choice Questions (MCQ)

Direct conceptual queries with 4 standard choices and a single correct key.

Software Analysis: Scans for question prefix (1., Q1:, வினா 1:), isolates 4 choices labeled (A)-(D) or (1)-(4), and extracts Answer: X.
FORMAT BLUEPRINT (COPY & PASTE READY) 
1. Which layer of the OSI model does a network router operate on?
(A) Physical Layer
(B) Data Link Layer
(C) Network Layer
(D) Transport Layer
Answer: C
Explanation: Routers operate at Layer 3 (Network Layer) to direct IP packet traffic between distinct networks.

[TAMIL VERSION]
வினா 1:
உலக சுற்றுச்சூழல் தினம் கொண்டாடப்படும் நாள் எது?
(A) ஜூன் 5
(B) ஜூலை 11
(C) செப்டம்பர் 16
(D) டிசம்பர் 1
சரியான விடை: A
விளக்கம்: ஒவ்வோர் ஆண்டும் ஜூன் 5 அன்று உலக சுற்றுச்சூழல் தினம் அனுசரிக்கப்படுகிறது.

Type 2 Comparative Table

Match the Following (பொருத்துக வினா)

Pairs terms between List I and List II. Automatically rendered as a clean 2-column comparative table.

Software Analysis: Triggered by keywords List I & List II (or பட்டியல் I & பட்டியல் II). Items labeled (A)-(D) and (I)-(IV) are aligned into columns.
FORMAT BLUEPRINT (COPY & PASTE READY) 
2. Match the Computer Protocols in List I with their Default Ports in List II:
List I (Protocols)
(A) HTTP
(B) HTTPS
(C) SSH
(D) DNS
List II (Port Numbers)
(I) 22
(II) 53
(III) 80
(IV) 443

Choose the correct answer from the options given below:
(A) (A)-(III), (B)-(IV), (C)-(I), (D)-(II)
(B) (A)-(I), (B)-(II), (C)-(III), (D)-(IV)
(C) (A)-(IV), (B)-(III), (C)-(II), (D)-(I)
(D) (A)-(II), (B)-(I), (C)-(IV), (D)-(III)
Answer: A
Explanation: HTTP defaults to Port 80, HTTPS to Port 443, SSH to Port 22, and DNS to Port 53.

Type 3 Dual Visual Cards

Assertion and Reason (உறுதிக்கூற்று - காரணம்)

Evaluates the truth value and causal relationship between an assertion and reason.

Software Analysis: Triggered by Assertion (A): and Reason (R): (or உறுதிக்கூற்று (உ): and காரணம் (கா):). Renders into two styled visual cards with dedicated color-coded badges.
FORMAT BLUEPRINT (COPY & PASTE READY) 
வினா 3 [உறுதிக்கூற்று - காரணம்].
உறுதிக்கூற்று (உ): வீரமாமுனிவர் இயற்றிய தேம்பாவணி காப்பியத்தின் முதன்மைப் பாட்டுடைத் தலைவன் வளன் (சூசையப்பர்) ஆவார்.
காரணம் (கா): தேம்பாவணி 3 காண்டங்களையும் 36 படலங்களையும் 3,615 விருத்தப் பாடல்களையும் கொண்டக் கிறித்துவச் சமயக் காப்பியமாகும்.

கீழே தரப்பெற்றுள்ள விருப்பங்களிலிருந்து சரியான பதிலத்தைத் தேர்ந்தெடுக்க:
(1) (உ) சரி, (கா) சரி; (கா) என்பது (உ)-விற்குச் சரியான விளக்கமாகும்
(2) (உ) சரி, (கா) சரி; ஆனால் (கா) என்பது (உ)-விற்குச் சரியான விளக்கமன்று
(3) (உ) தவறு, (கா) சரி
(4) (உ) தவறு, (கா) தவறு
சரியான விடை: (2)
விளக்கம்: கூற்றும் காரணமும் சரி; ஆனால் காப்பிய அமைப்புக் காரணம் பாட்டுடைத் தலைவனுக்கான நேரடி விளக்கமன்று.

Type 4 Statement Pill Badges

Statement-Based Questions (பல்கூற்றுத் தேர்வு வினா)

Evaluates 2 to 5 distinct statements using Roman numerals (i)-(iv) or Statement 1 & 2.

Software Analysis: Extracts prompt badge (பல்கூற்றுத் தேர்வு வினா), query instruction (...ஆராய்க:), and aligns each statement (i)-(iv) into isolated pill-card containers.
FORMAT BLUEPRINT (COPY & PASTE READY) 
90. பல்கூற்றுத் தேர்வு வினா
பெண்ணியக் கவிஞர்கள் பற்றிய பின்வரும் கூற்றுகளை ஆராய்க:
(i) 'கருவறை வாசனை' என்னும் கவிதைத் தொகுப்பைப் படைத்தவர் கனிமொழி.
(ii) 'இரவு மிருகம்' கவிதைத் தொகுப்பை எழுதியவர் சல்மா.
(iii) 'நீலமுடி', 'முதல் மனுசி' ஆகிய தொகுப்புகளை எழுதிய இளம்பிறையின் இயற்பெயர் பஞ்சவர்ணம்.
(iv) சுகிர்தராணியின் கவிதைகள் இயற்கை அழகியலை மட்டுமே பாடுகின்றன.

(அ) (i), (ii) மட்டும் சரி
(ஆ) (i), (iii) மட்டும் சரி
(இ) (ii), (iv) மட்டும் சரி
(ஈ) (i), (ii), (iii), (iv) அனைத்தும் சரி
பதில்: (ஆ) (i), (iii) மட்டும் சரி
விளக்கம்: கூற்றுகள் (i) மற்றும் (iii) சரியானவை. 'இரவு மிருகம்' சுகிர்தராணியின் தொகுப்பு.

Type 5 Timeline Sequence

Sequence / Chronological Order (காலவரிசை வினா)

Requires candidates to arrange historical events, publications, or steps in accurate temporal order.

Software Analysis: Triggered by காலவரிசை வினா, நிரல்படுத்துக வினா, or Arrange in chronological order:. Sets up ordered sequence pill cards and timeline flow.
FORMAT BLUEPRINT (COPY & PASTE READY) 
5. Arrange the following computer innovations in chronological order:
(i) Invention of the Transistor at Bell Labs
(ii) Launch of the World Wide Web (WWW)
(iii) Development of the C Programming Language
(iv) Invention of the Microprocessor (Intel 4004)

Choose the correct chronological sequence:
(A) (i) -> (iv) -> (iii) -> (ii)
(B) (i) -> (iii) -> (iv) -> (ii)
(C) (iv) -> (i) -> (iii) -> (ii)
(D) (ii) -> (i) -> (iii) -> (iv)
Answer: A
Explanation: Transistor (1947) -> Microprocessor (1971) -> C Language (1972) -> World Wide Web (1989).

Type 6 Comprehension Card

Passage-Based Questions (பத்தி வினாக்கள்)

A shared reading passage or data narrative linked to multiple consecutive questions.

Software Analysis: Scans for Directions: Read the following passage... Questions X to Y. Natively attaches the highlighted comprehension box to each sub-question.
FORMAT BLUEPRINT (COPY & PASTE READY) 
Directions: Read the following passage carefully and answer Questions 6 and 7:
Passage:
Photosynthesis is the biological process by which green plants convert light energy into chemical energy stored in glucose molecules. This reaction takes place inside chloroplasts using chlorophyll. Water molecules are split in the light reactions to release oxygen as a byproduct.

6. In which cell organelle does photosynthesis primarily take place?
(A) Mitochondria
(B) Chloroplast
(C) Ribosome
(D) Endoplasmic Reticulum
Answer: B
Explanation: Photosynthesis takes place inside chloroplasts.

Type 7 Data Interpretation

Mathematical Problem Solving & Data Tables

Tabular matrices using markdown pipes |, ratios, calculations, and formulas.

Software Analysis: Pipe tables (Col 1 | Col 2) are compiled into mobile-responsive HTML examination tables with sticky headers.
FORMAT BLUEPRINT (COPY & PASTE READY) 
8. The following table shows the production of cars (in thousands) by four companies from 2021 to 2023:
Company | 2021 | 2022 | 2023
Alpha | 40 | 55 | 70
Beta | 30 | 45 | 60
Gamma | 50 | 60 | 65
Delta | 20 | 35 | 50

What is the percentage increase in the production of cars by Company Alpha from 2021 to 2023?
(A) 50%
(B) 60%
(C) 75%
(D) 80%
Answer: C
Explanation: Production in 2021 = 40. Production in 2023 = 70.
Increase = 70 - 40 = 30.
Percentage Increase = (30 / 40) * 100 = 75%.

Checklist

Universal Do's & Don'ts Checklist

Ensure error-free parsing by following these 4 golden rules.

Category DO ✓ DON'T ✗
Question Numbers Start questions with 1., 2., Q1:, வினா 1: on a fresh line. Don't blend questions together in one continuous paragraph without a number.
Prompt Badges Keep பல்கூற்றுத் தேர்வு வினா or காலவரிசை வினா on its own line. Don't split titles like பல்கூற்று and த் தேர்வு வினா across two separate lines.
Statements Label statement items with (i), (ii), (iii), (iv). Don't write statements as raw paragraphs without any bullet or numeral marker.
Answer Keys Always end each question with Answer: X or சரியான விடை: X. Don't omit the answer line or put it before the options.
