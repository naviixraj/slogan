Master Administrator Help

How do I add a new Examination Set?
Click the + Upload Set button in the toolbar. Enter the exam title as you want candidates to see it, select an Excel (.xlsx), CSV, JSON, or PDF file, and click submit. The system will automatically parse and split each question.

What formats are supported?
• PDF (.pdf): Standard MCQ exam papers with numbered questions, options (A, B, C, D), and answers are automatically parsed.
• Excel (.xlsx) / CSV: Standard 7 columns (Question, Option A, Option B, Option C, Option D, Answer, Explanation). Bilingual questions (English and Tamil) are fully supported.
• JSON (.json): Array of question objects.

How are candidate logins managed?
Go to the Students tab from the sidebar. You can enroll candidates by creating their unique User ID and password. Passwords are saved with BCrypt encryption.
