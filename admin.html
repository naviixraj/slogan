Master Administrator Knowledge Base

Complete operational guide for managing examination papers, dynamic question banks, candidate security, and cloud sync.

Engine v2.4 Production Standard

1. Examination Set Management

Creating, uploading & customizing test papers

  1. File Uploads: Click + Upload Set. Upload Excel (.xlsx), CSV, JSON, or PDF exam papers. Columns and question numbers are automatically parsed.
  2. Bulk Text Pasting: Switch to the Paste Full Question Set tab to paste raw unformatted text. The live question counter validates questions prior to upload.
  3. Editing Metadata: Click ✏️ on any test card to update Title, Subject, or Duration (minutes).
  4. Deleting Test Sets: Click 🗑️ on any test card to remove the set and all associated questions.
Pro Tip: Changing an exam's duration or question count automatically synchronizes the candidate instructions screen in real time.

2. Question Inspector & Bank Editor

Visual reordering, in-place editing & bulk tools

  1. Hold & Drag Reordering: Press and hold any question card to drag it to a new position. The viewport smoothly auto-scrolls when dragging near the top or bottom edge.
  2. Single Question Editing: Click ✏️ Edit on any question card to edit the question statement, choices A–D, correct answer key, and explanation.
  3. Multi-Select & Bulk Delete: Tick question checkboxes to activate the floating bulk action bar. Click Delete Selected to remove multiple questions at once.
  4. Open Space Deselection: Click or tap anywhere in the empty/blank space outside cards to instantly clear all selected questions.
Auto-Scroll: Dragging a card to within 80px of the screen top/bottom scrolls the page continuously until dropped.

3. Live Exam Engine & Evaluation

Dynamic instructions, timer & anti-cheat

  1. Dynamic Exam Instructions: The instructions screen dynamically pulls live question counts and duration directly from the test paper configuration.
  2. Tamper-Proof Timer: The live countdown timer persists across browser refreshes and forces automatic submission when time expires.
  3. Anti-Cheat Shield: Automatically logs and warns candidates if fullscreen mode is exited or focus is switched away from the exam tab.
  4. Immediate Evaluation: Instant scorecard calculation with accuracy percentage, negative marking support, and question-by-question review.

4. Candidate & Student Administration

User credentials, access levels & security

  1. Enrolling Candidates: Navigate to the Students tab from the sidebar to register candidate usernames, names, and emails.
  2. BCrypt Security: All candidate passwords are encrypted using salted BCrypt hashing before database persistence.
  3. JWT Session Control: Authentication uses tamper-proof bearer tokens with strict role-based access checks.

5. Database Architecture & Cloud Sync

Supabase PostgreSQL cloud with SQLite fallback

  1. Cloud Persistence: Production runs on Supabase PostgreSQL with automated schema migration and real-time updates.
  2. High-Availability Fallback: If cloud network drops, the backend automatically transitions to an embedded SQLite engine for zero downtime.
  3. Data Integrity: All question updates and set deletions use transactional cascades to preserve relational integrity.

6. Standard Formats & Syntax

Excel columns, text paste patterns & bilingual text

Excel / CSV 7-Column Standard:

Question | Option A | Option B | Option C | Option D | Answer | Explanation

Bulk Text Paste Pattern:

1. Question Statement?
A) Choice 1   B) Choice 2
C) Choice 3   D) Choice 4
Answer: A
Explanation: Solution rationale.
Bilingual Ready: UTF-8 characters for Tamil, English, and scientific formulas are supported automatically.
